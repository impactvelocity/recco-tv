Fire TV style guide
Everything needed to rebuild the Recco TV app: theme tokens, type, surfaces, components, remote-focus behavior and background layers. Specimens below render live in the selected theme. Canvas is 1920×1080; all sizes are CSS px at that canvas.

01
Theme system
A theme is a flat set of CSS custom properties applied on the app root, plus a few JS-side values for focus. Every component reads only these tokens — never hard-coded colors. Seven themes ship; the default is fallDay. Users switch in Settings → Theme (Enter cycles).

02
Background layers
Stacked bottom → top, all position:absolute; inset:0. Default overlay is vignette at 100%. Video is muted, looped, autoplay, playsinline, object-fit:cover; set src from JS once the theme is known (never bind an unresolved template string).

05
Remote focus
Exactly one element is focused at a time; there is no mouse hover on TV — “hover” is the focus state. Focus is moved by D-pad using nearest-neighbour in the arrow direction (score = distance along axis + 2.5 × off-axis distance). Three focus treatments, chosen by element type:

Navigation & behavior
Remote keys: arrows, Select (Enter), Back (Backspace/Esc).
Context
Behavior
Launch
Inbox view; focus first card
Tabs
Focusing Featured/Inbox switches view; Down enters content
Inbox grid
Select opens drawer (single) or the stack list (stack). Grid scrolls to keep focus in view
Featured
One recco at a time; Left/Right flips (wraps). 84px arrow buttons + 16px dots (active = focus color). Card focus has no scale
Stacks are skipped
Drawer / Settings
Back or Left-at-edge closes; focus returns to the opener
Stack list
Back returns to Inbox. Unstack moves items into the Inbox; duplicates merge as extra recommenders
Settings
Theme (cycles), Text reccos to (number), Default view, Hide watched, Signed in as
Onboarding
Waiting → code (no focusable elements; advances when the text arrives) → Connected (~2s) → Inbox. Empty inbox focuses Settings
