# 60-second ad script

Female voiceover, first person. For a TV spot or TikTok. The full demo video script is in `demo-script.md`.

9pm. Tea, snacks, and an hour and a half before bed for a really good show.

But most nights, I spend ten minutes searching.
Then I remember Megan mentioned a show, so I grab my phone to find it...
and forty minutes later, I'm still scrolling.
Now there's no time for anything. So I scroll some more.
Not exactly me time.

So now I use Recco.
It's an inbox for my TV that I text like a friend.

Setup is easy. Install the Recco app on Fire TV, then text the code to the Recco number.
Now the Recco agent looks up every show I send and gets it ready for me.

Jill says a sitcom is hilarious. I text it, and it's on my TV.
Steph sends a video with three shows. One link, three reccos.

Texting is great because there's nothing to install, and it works on any phone.
I can send it anything: a link, a friend's pick, or "movies for a rainy night."
It just works.

So when it's me time, my phone stays off, and my inbox is full of reccos I actually want to watch.
All I have to do is tell Alexa which one.
